## 🚀 Getting Started

### **Prerequisites**
- Python 3.8 or higher
- Git
- Anaconda or pip
- Basic understanding of programming concepts (recommended)

### **Installation**

1. **Clone the repository:**
```bash
git clone https://github.com/yourusername/FSDS-with-GenAI.git
cd FSDS-with-GenAI
```

2. **Create a virtual environment:**
```bash
# Using Anaconda
conda create -n fsds python=3.9
conda activate fsds

# Or using venv
python -m venv fsds_env
source fsds_env/bin/activate  # On Windows: fsds_env\Scripts\activate
```

3. **Install dependencies:**
```bash
pip install -r requirements.txt
# or for specific modules, check their individual requirements.txt
```

4. **Start exploring:**
```bash
# Open Jupyter Notebook
jupyter notebook

# Or open in VS Code
code .
```
